# LineDraw 全自動使用教學

免費使用，無需網站帳號或 VIP。抽選仍使用你目前登入的 LINE 帳號。

## 1. 閱讀使用須知

首次開啟或使用須知更新時，閱讀內容後按「我已了解，開始使用」。不想繼續可按「離開 App」。這一步只保存本機確認紀錄，不會開啟 Android 無障礙權限。

## 2. 開啟無障礙輔助

無障礙服務具備讀取畫面及代表你操作的能力。LineDraw 用它辨識 LINE 活動頁、依設定加入店家好友及點擊抽選。確認安裝來源可信並理解用途後，再自行授權；啟用權限本身不會開始抽選。

① 在 LineDraw 開啟「設定 → 抽選輔助 → 無障礙服務 → 管理」。

② 閱讀說明，按「前往 Android 設定」。

③ 找到「LineDraw 全自動抽選輔助」。它可能位於系統的「已安裝的應用程式」「已下載的應用程式」或類似分類中，各品牌名稱可能不同。

④ 開啟該服務，閱讀系統權限說明，再依畫面按允許或確認；需要手機密碼時請本人完成。

⑤ 回 LineDraw「設定」，確認無障礙服務顯示「已啟用」。

## 3. 若出現「受限制的設定」

只有信任 APK 來源時，才進行以下操作：

① 到手機「設定 → 應用程式 → LineDraw 全自動」，或長按 App 圖示開啟 App 資訊。

② 在 App 資訊的「更多／⋮」選單找到「解除受限制的設定／允許受限制的設定」，依系統畫面完成確認。

③ 返回 LineDraw 的「管理 → 前往 Android 設定」，重新開啟「LineDraw 全自動抽選輔助」，再回 App 檢查狀態。

允許受限制的設定不代表服務已開啟。項目名稱與可用性會隨品牌、Android 版本及安裝方式不同；若找不到，查看無障礙頁的實際阻擋原因。受公司或家長管理的限制，請依管理政策聯絡管理者。

Google 官方說明：https://support.google.com/android/answer/12623953?hl=zh-Hant

## 4. 開始抽選

① 確認 LINE 已登入你要使用的帳號。

② 到「抽選」分頁按「同步」，依商品、地區及活動狀態篩選，再選取活動。

③ 在設定確認是否開啟「自動加入店家好友」與「自動接續新增活動」。

④ 按「檢查並開始」，閱讀本輪設定，再按「開始本次抽選」。保持手機解鎖、網路連線，避免同時操作 LINE。

⑤ 用浮動控制列暫停或停止。抽選點擊送出後會接續下一筆；「已送出」不代表中獎，實際結果請看 LINE 活動頁。

## 5. 關閉或排除問題

• 不再使用自動操作：先停止批次，再到同一個系統無障礙頁關閉「LineDraw 全自動抽選輔助」。

• 已開啟仍不能抽：確認服務名稱與目前安裝版本一致。重開機或更新後可再次檢查；若服務關閉，重新啟用並返回 App 確認。

• 同時安裝 VIP 版：各版服務與紀錄獨立，測試本版時請停止另一版批次。

• 尚未解決：到「設定 → 預覽診斷紀錄」查看原因；自行檢查後，可連同 App／Android／LINE 版本及手機型號回報 GitHub Issues，勿附帳密或驗證碼。
